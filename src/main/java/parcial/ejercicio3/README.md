# ejercicio 3

## requerimientos del enunciado

pendiente: agregar el enunciado completo y separar sus requisitos funcionales y tecnicos antes de implementar la solucion.

## criterios de implementacion y documentacion

- utilizar las estructuras de datos que solicite el enunciado; no reemplazarlas por otras por conveniencia.
- resolver el problema de la forma mas directa que cumpla todos los requisitos.
- no agregar patrones, bibliotecas, arquitecturas ni abstracciones avanzadas que no sean necesarias para el ejercicio.
- documentar de forma clara, descriptiva y breve.
- escribir la documentacion y los comentarios en minusculas, sin emojis.
- evitar comentarios obvios o explicaciones extensas que repitan lo que ya expresa el codigo.
- describir el proposito de los metodos y las operaciones relevantes. por ejemplo: "recorre la estructura y devuelve la cantidad de elementos que cumplen la condicion".
- incluir las validaciones y los casos de prueba que se desprendan del enunciado.
- mantener la solucion dentro de los temas y herramientas vistos en clase.
